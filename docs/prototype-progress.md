### Найденный и исправленный реальный баг: mobile-меню не снимало scroll-lock после закрытия

**Симптом**, воспроизведённый через реальный клик по настоящей кнопке ✕ (`.mobile-menu__close`,
не эмуляция): диалог закрывался (`open` пропадал), но `aria-expanded` у бургера оставался
`"true"`, а `document.body.style.overflow` оставался `"hidden"` — **страница переставала
скроллиться после закрытия меню**. Это нашлось только благодаря реальному браузерному тесту —
статические проверки такое в принципе не ловят.

**Диагностика перед правкой** (чтобы не чинить вслепую): причина — весь cleanup
(`aria-expanded`, `body.style.overflow`, возврат фокуса) висел ИСКЛЮЧИТЕЛЬНО на слушателе
`dialog.addEventListener('close', ...)`, а событие `close` в тестовом окружении не долетало —
проверено на **изолированном пустом `<dialog>`**, вообще не связанном с кодом сайта: тот же
результат (`fired: false`). Это указывает на особенность конкретного браузерного движка/
автоматизации, а не на баг именно этого скрипта — предположительно в реальных браузерах
пользователей (Chrome/Firefox/Safari/Edge) нативное событие `close` для `<dialog>` — давно и
широко поддерживаемая функция, отказ маловероятен. Тем не менее зависимость от единственного
события без резервного пути — объективно хрупкий дизайн.

**Исправление** (`src/components/Header.astro`): cleanup вынесен в отдельную функцию
`resetState()`, которая теперь вызывается СРАЗУ и напрямую из `close()` (путь кнопки ✕, клика по
фону, клика по пунктам меню) — без ожидания события. Слушатель `dialog.addEventListener('close',
resetState)` оставлен как resilience-сеть специально для нативного закрытия по Esc (у него нет
отдельного вызова `close()` из кода сайта) — двойной вызов идемпотентен, вреда не наносит.

**Ретест после фикса** (тот же реальный путь — клик по настоящей кнопке ✕): `ariaExpanded:
"false"`, `bodyOverflow: "clip visible"` (норма сайта), фокус корректно возвращён на бургер.

```css
  animation: telegram-pulse 2.6s ease-out infinite;
}
.floating-telegram::after { animation-delay: 1.3s; }
@keyframes telegram-pulse {
  0%   { transform: scale(0.92); opacity: 0.5; }
  100% { transform: scale(1.5);  opacity: 0;   }
}
```

Длительность 2.6s (в диапазоне 2.4–2.8s), вторая волна — сдвиг ровно на половину цикла (1.3s),
