# Content Integrity

Существующий сайт является источником реальных бизнес-фактов.

Для товара сохраняй sourceUrl.

Для используемых assets сохраняй исходный URL.

Не придумывай:

* цены;
* характеристики;
* совместимость;
* сроки;
* гарантии;
* сертификаты;
* телефоны;
* адреса;
* email;
* производственные показатели.

Если данных нет:

UNKNOWN — как маркировка во внутренних данных/документации. В UI для посетителя вместо
`UNKNOWN` показывается нейтральный плейсхолдер (например, «Цена по запросу»), не правдоподобная
догадка.

Если данные противоречат:

DATA_REVIEW_REQUIRED

При конфликте:

1. сохрани оба значения;
2. сохрани URL источников;
3. не выбирай правильный вариант самостоятельно.

Можно улучшать:

* UX-copy;
* структуру;
* заголовки интерфейса;
* CTA.

Но нельзя менять технический или коммерческий смысл.

Не используй случайные AI-generated изображения как реальные фотографии продукции СТ-ТЕХНИКС.

Все формы прототипа работают только в mock-режиме.
