# ST-Technics Design

Сайт должен выглядеть как современный B2B-сайт реального производителя навесного оборудования.

Он должен передавать:

* производство;
* тяжёлую технику;
* инженерность;
* надёжность;
* практичность.

Основной визуальный материал:

* реальные фотографии оборудования;
* реальные фотографии техники;
* реальные фотографии производства.

Не превращай сайт в:

* generic AI landing page;
* SaaS;
* crypto;
* шаблонный Tilda;
* бытовой интернет-магазин.

Избегай:

* чрезмерного glassmorphism;
* бессмысленных gradients;
* огромных пустых hero;
* случайных stock photos;
* лишней анимации;
* чрезмерного количества rounded cards.

## UX paths

Путь 1:

Каталог
→ категория
→ товар
→ характеристики
→ запрос

Путь 2:

Тип техники
→ совместимое оборудование
→ товар
→ характеристики
→ запрос

## Specifications

Технические характеристики — важнейший контент.

Таблицы должны:

* хорошо читаться;
* работать на mobile;
* не обрезать значения;
* поддерживать разные schemas данных.

## Responsive

Проверяй:

* desktop;
* laptop;
* mobile;
* header;
* catalog;
* filters;
* product gallery;
* breadcrumbs;
* длинные названия;
* specification tables;
* CTA;
* forms.

## Accessibility

Используй:

* semantic HTML;
* heading hierarchy;
* keyboard controls;
* labels;
* alt;
* visible focus states.
